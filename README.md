## 📖 Overview

**WWE Universe** is an ultra-modern, production-grade Progressive Web Application (PWA) engineered to deliver an authentic, lag-free, and electrifying digital experience for wrestling fans worldwide. 

Featuring **100% authentic high-resolution superstar photography**, real legal names, billed measurements, live auto-updating news tickers, universal interactive modals, dedicated championship trackers, WrestleMania 42 ticket reservation simulations, and a full-featured Performance Center contract portal.

---

## ✨ Core Features & Highlights

### 1. 🏆 Dedicated "Reign of Champions" Hub (`/champions`)
- Real-time active titleholders (*Cody Rhodes, Gunther, Rhea Ripley, Bron Breakker, LA Knight, Nia Jax*).
- Live reign duration counters (e.g. `330 Days Held`).
- Hall of Championship Legacy milestone metrics (longest reigns, historic records).
- One-click trigger for interactive combat dossier modals.

### 2. ⚡ Live Auto-Updating News Desk & Bulletin Ticker
- Real-time auto-synchronizing ticker powered by `wweLiveFeedService.js`.
- Dynamic timestamps (`Just now (Live)`, `10 mins ago`, `2 hours ago`).
- Universal **News Article Reader Modal** with cheering counter, social sharing, and related tag filtering.
- Community fan journalism publishing engine with live feed integration.

### 3. 🥊 Authentic WWE Superstars Directory (`/superstars` & `/card/:id`)
- Real high-resolution local images for all 16 marquee athletes (*Roman Reigns, Cody Rhodes, Rhea Ripley, Gunther, Seth Rollins, CM Punk, The Rock, John Cena, Bianca Belair, etc.*).
- Verified legal names, entrance theme anthems, signature arsenal, and hometowns.
- Detailed combat attribute meters (*Power, Speed, Charisma, Technical*).
- Multi-criteria brand and division filters with instant live search.

### 4. 📺 Flagship Shows & Premium Live Events (`/event`)
- Broadcast schedule for **Monday Night Raw**, **Friday Night SmackDown**, and **WWE NXT**.
- Upcoming PLE Calendar: **WrestleMania 42** (Las Vegas), **Royal Rumble**, **SummerSlam**, and **Survivor Series WarGames**.
- Live interactive WrestleMania 42 countdown flip-clock.
- Fan match prediction voting ring with animated percentage updates.
- Priority Pass seating tier selection & ticket reservation modal.

### 5. 📝 WWE Performance Center & Contract Portal (`/contact`)
- Official NIL (Next In Line) collegiate and independent wrestling contract tryout application.
- Athletic tape submission, background classification, and physical measurement verification.
- Instant official receipt generator with unique Talent Tracking IDs (`WWE-TALENT-XXXXXX`).
- VIP ringside hospitality and Stamford Corporate HQ contact directory.

### 6. 📲 Progressive Web App (PWA) Architecture
- **Offline First**: Service Worker (`public/sw.js`) with Cache-First static asset delivery and Stale-While-Revalidate data fetching.
- **Cross-Platform Installability**: 1-click install button on Desktop (Chrome/Edge), Android, and 2-step guided modal for Apple iOS Safari (*"Share ⎋ -> Add to Home Screen ➕"*).
- **Standalone Display**: Fullscreen native app window with custom splash branding and status bar styling.

## 🔍 SEO & AEO (Answer Engine Optimization)

This project implements enterprise-grade search and AI answer engine optimizations:

- **JSON-LD Schema.org Structured Data**:
  - `SportsOrganization`: World Wrestling Entertainment & TKO Group Holdings metadata.
  - `SportsEvent`: WrestleMania 42 dates, venue (Allegiant Stadium), and lineup.
  - `FAQPage`: Rich snippets for AI search engines (ChatGPT, Google Gemini, Perplexity, Bing Copilot).
- **Complete Meta Suite**: Open Graph (Facebook/LinkedIn) and Twitter Cards with large image previews.
- **Search Bots Indexing**: `robots.txt` and clean `sitemap.xml` for instantaneous crawling.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/sunilpaudyal18/WWE.git
cd WWE
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start the local development server:**
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173/`.

4. **Build for production:**
```bash
npm run build
```
The optimized bundle will be created in the `dist/` directory.
